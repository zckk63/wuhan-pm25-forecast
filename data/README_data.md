# 数据来源与版本说明

## 数据来源和范围

候选数据来自 [Quotsoft 中国空气质量历史数据归档](https://quotsoft.net/air/)。归档页面注明数据来自中国环境监测总站发布的信息；本项目使用归档副本，不是官方实时接口。

数据是武汉城市级逐小时记录，不等同于单个监测站序列。预测目标为下一小时 PM2.5 浓度，单位为 μg/m³。项目只使用 `type == PM2.5` 的小时记录，不把 `PM2.5_24h` 当作小时值。

## 2025 年数据核验

项目已取得 365 个日文件，并生成带下载地址和 SHA-256 校验值的来源清单。

- 年内预期小时数：8760
- 有效 PM2.5 小时值：8432
- 缺失小时：328，缺失率 3.7443%
- 缺失原因：138 小时没有 PM2.5 原始记录，190 小时有记录但浓度为空
- 最长连续缺失：20 小时
- 完整的 24 小时日：244 天

训练目标是时刻 t 之后一小时的 PM2.5。候选滞后特征使用 t、t-1、t-2、t-3、t-6、t-12、t-24 小时的观测值。共有 7078 条特征和目标均完整的样本，按目标时间切分为训练 5625 条、验证 529 条、测试 924 条。

缺失值保留为空；不插值生成虚假的实测值。缺失目标的样本不参与训练和评分。

## DVC 数据版本计划

- **v1：** 原始日文件、来源清单，以及保留缺失值的 8760 小时标准表，可用于基线训练。
- **v2：** 在 v1 基础上生成无未来信息泄漏的滞后特征表，并附上质量报告和时间切分样本统计。
- Git 保存代码、说明和 DVC 指针；DVC 管理数据文件，Azure 保存远程数据对象。

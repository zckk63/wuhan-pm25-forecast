# Wuhan Next-Hour PM2.5 Forecast

本项目使用武汉 2025 年逐小时空气质量历史数据，训练回归模型预测下一小时的 PM2.5 浓度。应用提供历史时刻回放，不代表实时监测或实时预报。

## 数据范围

候选数据来自 [Quotsoft 中国空气质量历史数据归档](https://quotsoft.net/air/)，来源页注明数据来自中国环境监测总站发布的信息。数据按小时整理为武汉城市级记录，不等同于单个监测站的实测序列。

初步审计中，PM2.5 缺失率约为 3.74%，最长连续缺失约 20 小时。项目会保留缺失情况，不把缺失值伪装成实测值；数据版本、处理方式和来源将在数据说明中记录。

## 预测与评估

- 预测目标：时刻 t 之后一小时的 PM2.5 浓度。
- 特征只使用预测时点已经可获得的信息。
- 按时间划分训练、验证和测试数据：1—9 月、10 月、11—12 月。
- 使用“下一小时等于当前小时”的简单基线，并与机器学习模型比较。
- 主要指标：MAE 和 RMSE。

## 可复现与交付

项目计划使用 DVC 管理数据版本和 Azure 远程存储，使用 MLflow 记录训练实验，使用测试和 GitHub Actions 检查代码，并构建 Docker 镜像运行 Streamlit 应用。
